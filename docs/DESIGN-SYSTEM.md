ที่มาของทุกค่า: Google Drive → `Okamoo/` (BRANDBOOK, COLOR, FONT, LOGO)

## 1. สี

ค่าทั้งหมดมาจาก `Okamoo/COLOR/BRAND COLOR.pdf` **ห้ามแก้ค่าเจ็ดตัวนี้**

| ชื่อในคู่มือ       | Pantone      | HEX       | บทบาทในแอป                                      |
| ------------------ | ------------ | --------- | ----------------------------------------------- |
| Grilled Pork Brown | 1685 C       | `#722815` | สีหลัก — header, bottom nav, พื้นเข้ม, ปุ่มรอง  |
| Amber Flame        | 170 C        | `#FF825C` | accent อ่อน — ไฮไลต์บนพื้นเข้ม, ไล่เฉด          |
| Piglet Cream       | 3596 C       | `#E8BD84` | พื้นครีม, เส้นคั่นบนพื้นเข้ม, โลโก้บนพื้นน้ำตาล |
| Freshy Orange      | Orange 021 C | `#E24305` | สี CTA — ปุ่มหลัก, ราคา, ป้ายลดราคา             |
| Yellow Pop         | 106 C        | `#F9EF7A` | ป้ายที่ต้องสะดุดตาจริง เช่น "ขายดี" ใช้ให้น้อย  |

| Charcoal Black     | 7553 C       | `#473E37` | สีตัวอักษร                                      |

### หลักการใช้

- **น้ำตาล = ตัวตนของแบรนด์** ใช้กับโครงของแอป ไม่ใช่กับปุ่มที่อยากให้กด
- **ส้มไฟ = ของร้อน** สงวนไว้ให้ action หลักและราคาเท่านั้น ถ้าใช้กับทุกอย่างจะไม่เหลือแรงดึงดูด
- **เหลือง Pop ใช้เป็นจุด ๆ** หนึ่งหน้าจอไม่ควรเกิน 1–2 จุด
- ห้าม hardcode ค่าสีในคอมโพเนนต์ ให้อ้างผ่าน token เสมอ (`bg-brand-700`, `text-flame-600`)

### ข้อยกเว้นที่ตั้งใจ

1. **ปุ่มหลักใช้ `--flame-600` (`#C23A04`) ไม่ใช่ `#E24305`**
   Freshy Orange แท้ ๆ ให้คอนทราสต์กับตัวอักษรสีขาวแค่ **4.17:1** ซึ่งไม่ผ่าน WCAG AA (ต้อง ≥ 4.5)
   จึงเข้มขึ้นหนึ่งสเต็ปเฉพาะตอนมีตัวหนังสือทับ ส่วนที่ไม่มีตัวอักษรยังใช้ `#E24305` ตามคู่มือ

2. **สีสถานะ (success / warning / danger) ไม่ได้อยู่ในพาเลตแบรนด์**
   จำเป็นต้องมีเพื่อสื่อสถานะออเดอร์ เลือกโทนอุ่นให้กลมกลืน และห้ามใช้แทนสี CTA

`src/styles/__tests__/contrast.test.ts` อ่าน `tokens.css` โดยตรงแล้วเช็คคอนทราสต์ทุกคู่
ถ้าใครแก้ token จนคอนทราสต์ตก test จะพัง — ตั้งใจให้เป็นแบบนั้น

## 2. ตัวพิมพ์

คู่มือกำหนดสามชั้น:

| ชั้น        | TH                 | EN                 |
| ----------- | ------------------ | ------------------ |
| Primary     | FC Orbit           | Ruddy (Adobe Font) |
| Secondary   | Sarabun            | Poppins            |
| Google Font | IBM Plex Sans Thai | Montserrat         |

**เว็บแอปใช้ชั้น Google Font** เพราะ FC Orbit และ Ruddy ยังไม่มี webfont license
สแตกใน `--font-display` เขียน `'FC Orbit'` ไว้หน้าสุดแล้ว ถ้าซื้อ license เมื่อไหร่
แค่ self-host ไฟล์ฟอนต์ หน้าเว็บจะเปลี่ยนไปใช้ทันทีโดยไม่ต้องแก้โค้ด

| Token            | สแตก                                       | ใช้กับ                    |
| ---------------- | ------------------------------------------ | ------------------------- |
| `--font-display` | FC Orbit → Montserrat → IBM Plex Sans Thai | หัวข้อ ชื่อเมนู ราคา ปุ่ม |
| `--font-sans`    | IBM Plex Sans Thai → Sarabun               | เนื้อความ ตัวเลือก ฟอร์ม  |
| `--font-mono`    | IBM Plex Mono                              | รหัสออเดอร์ หมายเลขคิว    |

## 3. โลโก้

มาร์คคือตัว **O ที่มีหูหมู** อยู่ใน `public/brand/`

| ไฟล์                                   | ใช้เมื่อ                |
| -------------------------------------- | ----------------------- |
| `okamoo-mark-cream.png`                | พื้นเข้ม (น้ำตาลแบรนด์) |
| `okamoo-mark-brown.png`                | พื้นสว่าง               |
| `favicon.png` · `apple-touch-icon.png` | ไอคอนแอป                |

ใช้ผ่านคอมโพเนนต์ `<BrandMark tone="cream" size={40} />` ไม่ต้องอ้าง path เอง

**ลายพื้นหลัง** `.bg-brand-pattern` โปรยมาร์คบนพื้นน้ำตาลแล้วกดความเข้มเหลือราว 10%
ถอดแบบมาจากหน้าลายในเมนูเล่มจริง ตั้งใจให้เป็นพื้นผิว ไม่ใช่ลวดลายเด่น

## 4. รูปทรงและระยะ

โลโก้เป็นเส้นโค้งปลายมน ทั้งระบบจึงใช้มุมมนค่อนข้างเยอะ

`--radius-xs 8` · `--radius-sm 12` · `--radius-md 16` · `--radius-lg 22` · `--radius-xl 28` · `--radius-pill 999`

เงาเป็นโทนอมน้ำตาล (`--shadow-card`, `--shadow-raised`) ไม่ใช้เงาเทากลางเพราะจะดูเย็นตัดกับพื้นครีม
ปุ่ม CTA มีเงาส้ม (`--shadow-cta`) เพื่อยกให้ลอยขึ้นมาจากหน้า

Touch target ขั้นต่ำ `--tap-min: 44px` ทุกปุ่มต้องผ่าน
